# Smart-Quiz-System🧠💻

A console-based quiz application developed in C using file handling. This system allows users to sign up, log in, take quizzes, and view their scores. It also includes an admin panel to create and manage quizzes.

## 🚀 Features

### 👤 User Features
- Sign up and login  
- Take quizzes  
- View scores  

### 🔐 Admin Features
- Add new quizzes  
- Manage quiz questions  

### 💾 Data Storage
- Uses text files for storing users, quizzes, and results  

## 🛠️ Technologies Used
- C Programming  
- File Handling  

## 📂 Project Files
- `main.c` – Main program  
- `user.txt` – Stores user credentials  
- `admin.txt` – Stores admin credentials  
- `quizzes.txt` – List of quizzes  
- `results.txt` – Stores quiz results  
- `1 sampleQuiz.txt` – Sample quiz file 

## ▶️ How to Run
- Compile and run using:
  gcc main.c -o quiz  
  ./quiz
